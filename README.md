## Overview
An installable, offline-first Android Progressive Web App (PWA) for tracking and verifying the 6-Month Research, Technical Writing, and AI Evaluation Portfolio Blueprint:
- **11 Dedicated Views**: Overview & Today Command View, Daily 115-Min Protocol (`Date.now()` Wake Lock Timer), 24-Week Schedule with Proof-Link Verification, Monthly KPIs (`M1–M6`), 7-Tier Proof Staircase, Projects Hub (`P0–P5`), Research Methodology, Technical Writing (`Diátaxis` + Day 1 GeoPandas Guide), Technical Prep & 90s Leitner Flashcards, Career & Paid Hours Logger, and Artifact-Specific 100-Point Rubric.
- **Installable Android PWA**: Includes `manifest.json`, `sw.js` offline Service Worker, `192x192` & `512x512` standard + maskable PNG icons, `.ics` calendar export, and full JSON state backup/restore.

## Live GitHub Pages Deployment
1. Go to **Settings -> Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **`main`** and folder **`/ (root)`**, then click **Save**.
4. Open `https://mkmeheran.github.io/Execution-Blueprint-/` in Android Chrome and tap **Install** to add the app to your Home screen.
